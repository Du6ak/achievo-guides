# Achievo Guides

Открытый репозиторий базы пользовательских руководств Achievo. Сейчас база пуста: проверенных руководств и подтверждённых схем достижений в ней нет.

Лицензия базы, условия использования материалов и правила модерации ещё не утверждены. Публичная отправка из Achievo и автоматическая публикация отключены; наличие репозитория не означает, что предложения уже принимаются. Не добавляйте чужие материалы до определения условий и подтверждения прав.

## Структура

```text
guides/{appId}/{language}/{achievementKey}/{guideId}.md
guides/{appId}/{language}/{achievementKey}/assets/{guideId}/{sha256}.png
schema/guide.schema.json             схема метаданных Markdown v1
schema/steam-achievements.json       локальный снимок подтверждённых API-имён
tooling/                            общий с Achievo валидатор и сборщик
public/v1/catalog.json              начальный пустой статический каталог
```

`achievementKey` — SHA-256 UTF-8 исходного API-имени достижения, в нижнем регистре шестнадцатеричной записи; `guideId` — UUID. Файл — UTF-8 Markdown с YAML Front Matter. Изображения PNG перечислены в манифесте и указываются относительным путём. Подробности, ограничения и совместимость старого v1 — в [FORMAT.md](FORMAT.md).

`public/v1` — зафиксированный пустой снимок, а не настроенный процесс публикации. Achievo может читать его по адресу `https://raw.githubusercontent.com/Du6ak/achievo-guides/main/public/v1/`. При появлении материалов снимок сам не обновится: защищённый процесс публикации ещё предстоит определить.

## Локальная проверка

Нужны JDK 21 и доступные зависимости Gradle. Из корня этого репозитория:

```powershell
.\gradlew.bat guideTools
java -jar .\tools\guide-tools.jar validate .
java -jar .\tools\guide-tools.jar check-title-set .
java -jar .\tools\guide-tools.jar build . build\catalog
```

На Linux/macOS используйте `./gradlew guideTools` и обычные `/` в путях. Проверка работает локально и не отправляет файлы в сеть; исходная загрузка Gradle и зависимостей может требовать интернет. `validate` проверяет пути, метаданные, формат, содержимое, UUID, переводы, изображения и указанные API-имена. `check-title-set` дополнительно проверяет совпадения названий полного локального набора, но сам по себе не защищает от конкурентных изменений или слияний. `build` создаёт совместимый каталог в `build/catalog/v1/` и не изменяет `public/v1`.

`schema/steam-achievements.json` намеренно пуст: он не подтверждает достижения. Реальные API-имена можно добавлять только после выбора и подтверждения источника и политики обновления схем. Сбой проверки не означает, что имя свободно или гайд принят.
